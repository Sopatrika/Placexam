

Pour importer un tableau EXCEL sur Placexam, voici les conditions :

Si le fichier exporté contient une liste d'étudiants, il faut au moins avoir les colonnes présente :
- NOM
- PRENOM
- PARCOURS (option, filière...)

Le tableau dans le fichier doit être dans cette configuration :

|  NOM  | PRENOM |  PARCOURS |
| Lutin |  Marc  |  PARCOUR1 |
| Lutin |  Marc  |  PARCOUR1 |
| Lutin |  Marc  |  PARCOUR1 |

Si le fichier exporté contient une liste des places d'une salle, il faut être composé que d'une seule colonne :
- PLACE (nom des places des salles d'examen (1, 2, 3...))
